Abrir lección

    Ayuda

    Cómo practicar

    1. Abre una lección en Lecciones → Abrir lección.
    2. Lee la lección y fíjate en su objetivo.
    3. Escribe tú mismo el código en el editor.
    4. Pulsa Compilar. Si hay errores, léelos en la consola.
    5. Si compiló bien, pulsa Ejecutar para ver el resultado.

    Objetivos: cada lección dice qué debes lograr (provocar un error de compilación, compilar bien, provocar un error de ejecución o ejecutar con éxito). El sistema lo verifica solo.

    Configuración: cambia el tamaño de la fuente y el tema claro u oscuro. Se guardan para tu próximo ingreso.

    Tu código de ingreso: guárdalo. Con él puedes volver y ver tu historial.

    Límites: no se puede leer texto del teclado (Scanner), solo un archivo y sin librerías externas.

    Importar compendio de lecciones

    Selecciona un .zip con una o más carpetas de lección (cada una con leccion.md y config.txt). Si ya existe una lección con el mismo título, se actualiza.
